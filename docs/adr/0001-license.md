# ADR 0001: Use AGPL-3.0-only

## Status

Accepted

## Context

OpenRewrite Studio is intended to be open-source and self-hostable while also supporting a hosted cloud business.

## Decision

Use `AGPL-3.0-only` for the project.

## Consequences

Hosted modifications must remain open under AGPL terms. This protects the community edition from opaque hosted clones, but it can reduce adoption by companies that prefer permissive licensing.
